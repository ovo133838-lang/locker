## 2 里程碑

| 里程碑 | 内容 | 累计人日 | 判定 |
| --- | --- | --- | --- |
| M1 | W00–W02 | 4.0 | 服务可启、基座接入、迁移成功、登录可用 |
| M2 | W04–W05 | 8.5 | 能创建订单并完成支付回调 |
| M3 | W06–W07 | 13.5 | mock 柜体下全流程跑通（含退款与补交） |
| M4 | W08–W09 | 18.0 | B 端接口冒烟全通 |
| M5 | W10–W11 | 25.0 | 小程序与后台可按原型走查 |
| M6 | W12–W13 | 31.0 | P0 清零、AC-01~16 通过 |
| M7 | W14 | 32.5 | 生产真实开门 + 真实退款验证 |

关键路径：W00→W01→W04→W05→W06→W07→W12。任一环节返工都顺延验收与上线；前端可在 M2 之后并行，前提是契约与 mock 数据先就绪。

## 4 风险

| 编号 | 风险 | 应对 |
| --- | --- | --- |
| R1 | 柜体协议未提供，回执字段不确定 | mock 先跑通业务，同步索要字段清单；协议到位后替换 Adapter |
| R2 | 微信支付商户号未就绪 | 沙箱 + 模拟回调，上线前真实小额验证 |
| R3 | 待确认项改变定价或退款规则 | 规则参数化 + 快照字段预留 |
| R4 | 单格口并发暴露超卖 | 条件更新 + 唯一索引 + 压测用例进提测门禁 |
| R5 | 上线初期异常率高 | 灰度一个网点，异常合并 + 值守响应 |

## 6 变更控制

影响金额、状态、接口字段的变更一律走变更单：原因、影响任务、追加人日，确认后改代码。未确认的变更按缺陷处理，不占原排期。

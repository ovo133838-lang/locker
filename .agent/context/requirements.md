> 全文见《优小宝智能寄存柜_业务需求说明书.docx》。本文件只保留 Agent 写代码时会用到的编号、状态与判定条件；规则细节以原文第三章为准。

## 1 角色与端

| 角色 | 端 | 关键操作 |
| --- | --- | --- |
| 寄存用户 | C 端小程序 | 找柜、选柜型与时长、支付、开门、临时开门、结束取出 |
| 网点管理员 | B 端后台 | 巡检柜组、远程开门、结束订单、退费、处理异常、看营收 |
| 平台运营 | B 端后台（平台侧） | 新建网点、配置规则、跨网点经营分析 |
| 柜体终端 | 柜体屏幕 | 扫码寄存 / 取物兜底、开门异常重试 |

## 3 订单状态机

| 状态 | 进入条件 | 文案 | 可执行 | 终态 |
| --- | --- | --- | --- | --- |
| pending_pay | 提交下单未支付 | 待支付 | 支付、取消、超时自动取消 | 否 |
| active | 支付成功且开门回执成功 | 进行中 | 临时开门、结束取出 | 否 |
| overdue | 超计划时长或已付不足 | 已超时、需补交 | 补交并取出、临时开门 | 否 |
| closed | 正常结束且余额已退 | 已结束 | 查看明细、联系客服 | 是 |
| canceled | 支付超时或用户取消 | 已取消 | 重新下单 | 是 |

允许迁移：pending_pay→active、pending_pay→canceled、active→overdue、active→closed、overdue→closed。终态不回退。每次迁移写 `audit_logs`（状态、时间、触发方）。

## 4 柜门状态

| 状态 | 可分配 | 变更方式 |
| --- | --- | --- |
| normal | 是 | 关单自动释放；管理员手动改回（须无进行中订单） |
| used | 否 | 下单占用、关单释放 |
| err | 否 | 设备上报或管理员标记 |
| off | 否 | 管理员停用 |
| broken | 否 | 管理员标记或维保回写 |

有进行中订单的柜门只允许改为 `err` 或保持 `used`，不得改为 `normal`。

## 5 异常

| 类型 | 判定 | 级别 | 响应 |
| --- | --- | --- | --- |
| door_open | 回执成功后门磁仍报开启，或关单后仍开启 | err | 5 分钟 |
| unexpected_open | 非线上与管理员操作被打开 | err | 10 分钟 |
| offline | 心跳连续缺失 | warn | 30 分钟 |
| hardware | 门磁、锁体故障 | err | 按维保 |

异常记录必须含产生时间、网点柜组柜号、关联订单、处理动作、处理人、关闭时间、说明；未处理不得自动消失；同柜组同类 30 分钟内合并。

## 6 统计口径（不得混用）

| 指标 | 口径 |
| --- | --- |
| 今日收益 | 当日结束订单寄存费合计 − 当日退款合计，不含押金 |
| 今日订单数 | 当日创建订单数，含进行中（与收益口径不同，页面须标注） |
| 本月营收 | 本月结束订单寄存费 − 本月退款 |
| 下单转化率 | 当日下单人数 ÷ 浏览网点详情人数（去重） |
| 异常待处理数 | `handled=0` 的条数，与异常页未处理数一致 |
| 柜门使用率 | 进行中格口 ÷ 可分配格口（分母不含停用与损坏） |

## 7 验收清单

| 编号 | 验收项 | 判定 |
| --- | --- | --- |
| AC-01 | 找柜与搜索 | 定位成功按距离排序；无结果给空态；休息中不可下单 |
| AC-02 | 柜型与时长 | 余量为零不可选；预估金额与单价、封顶、押金一致 |
| AC-03 | 规则告知 | 未勾选不可支付；价格与后台配置同源 |
| AC-04 | 支付与开门 | 支付成功才开门；开门成功才计时；失败可重试一次 |
| AC-05 | 订单详情 | 剩余时长递减；当前费用与算例一致；余额正确 |
| AC-06 | 临时开门 | 不结束、继续计时、记入开门记录 |
| AC-07 | 结束与退款 | 余额为正原路退回；为负转已超时须补交 |
| AC-08 | 免费时长 | 10 分钟内结束全额退回、费用为 0 |
| AC-09 | 订单列表 | 分组正确；已超时显示补交金额 |
| AC-10 | 柜组状态 | 五态正确；有订单的格口不可改正常 |
| AC-11 | 远程开门与改状态 | 即时更新并留痕 |
| AC-12 | 订单处置 | 管理员关单按实际时长结算并填原因 |
| AC-13 | 营收看板 | 不含押金，退款按发生日扣减，可与明细对平 |
| AC-14 | 异常闭环 | 可处理、可留痕，未处理数一致 |
| AC-15 | 收费规则 | 改后只对新单生效，进行中不变 |
| AC-16 | 通知 | 关键节点可达；未授权走短信兜底 |

## 8 非功能基线

开门指令点击到柜门打开 ≤ 3 秒；首屏 ≤ 3 秒；单网点 1000 条订单查询 ≤ 1 秒；单网点并发下单 50 单/分钟；概览 5 分钟同步一次并在页面标注时间。手机号列表与详情脱敏，仅处置订单时可看完整号码；支付敏感信息不落库，仅存交易号。
